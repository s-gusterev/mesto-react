# Mesto — React-версия учебного проекта

Интерактивный сервис публикации фотографий «Mesto», реализованный на React. Приложение получает и изменяет данные через публичный API Яндекс.Практикума: профиль пользователя, аватар, карточки с фотографиями, лайки.

## Демо

- URL: [GitHub Pages](https://s-gusterev.github.io/mesto-react/)

## Функциональность

- Просмотр профиля пользователя и аватара.
- Редактирование имени и описания профиля.
- Обновление аватара пользователя.
- Просмотр списка карточек с фото; открытие полноразмерного изображения (popup).
- Добавление новой карточки (название + ссылка на изображение).
- Удаление собственной карточки.
- Лайк/анлайк карточки с мгновенным обновлением счётчика.

## Технологии

- React 18, функциональные компоненты и `useState`/`useEffect`/Context API.
- CRA (`react-scripts`) для локальной разработки и сборки.
- Fetch API для работы с REST.
- БЭМ‑архитектура, модульные CSS, `normalize.css`.
- Шрифты Inter, адаптивные сетки (Flex/Grid в стилях проекта).

## Быстрый старт

Предусловия: установлен Node.js и npm.

1) Установка зависимостей:

```bash
npm install
```

2) Локальная разработка:

```bash
npm start
```

Приложение откроется на `http://localhost:3000`.

3) Сборка продакшн‑версии:

```bash
npm run build
```

4) Тесты (если добавлены):

```bash
npm test
```

Примечание: в проекте используется старая версия `react-scripts`. При несоответствии версий Node/браузера обновите окружение или зафиксируйте Node LTS (например, 14/16).

## Доступные скрипты

- `npm start` — запуск dev‑сервера.
- `npm run build` — сборка в папку `build/`.
- `npm test` — запуск тестов в JSDOM.
- `npm run eject` — извлечение конфигурации CRA (необратимо).

## Структура проекта

- `public/` — HTML‑шаблон и ассеты для сборки.
- `src/index.js` — входной файл React‑приложения.
- `src/components/` — UI‑компоненты (карточки, попапы, шапка/футер и т.д.).
- `src/contexts/CurrentUserContext.js` — контекст текущего пользователя.
- `src/utils/api.js` — клиент для работы с API.
- `src/blocks/` — стили по БЭМ‑блокам.
- `src/index.css` — агрегатор стилей.

## API

Работа с публичным API «Mesto» Яндекс.Практикума:

- База: `https://mesto.nomoreparties.co/v1/cohort-39`
- Авторизация: токен передаётся в заголовке `authorization` (см. `src/utils/api.js`).
- Эндпоинты, используемые приложением:
  - `GET /users/me` — профиль.
  - `PATCH /users/me` — обновление профиля.
  - `PATCH /users/me/avatar` — обновление аватара.
  - `GET /cards` — список карточек.
  - `POST /cards` — добавление карточки.
  - `DELETE /cards/:cardId` — удаление карточки.
  - `PUT/DELETE /cards/:cardId/likes` — лайк/анлайк.

Все запросы и обработка ответов инкапсулированы в `src/utils/api.js`.

## Развёртывание на GitHub Pages (опционально)

В проект уже добавлен пакет `gh-pages`. Для публикации можно добавить скрипты в `package.json`:

```json
"homepage": "https://<username>.github.io/<repo>",
"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d build"
}
```

Затем выполнить:

```bash
npm run deploy
```
